Pick for the map. Not for the hype.

Choose the map, tap what your teammates locked, and see the best picks left for you, plus full team comps. Every suggestion says why, how much data is behind it, and how old that data is. In a 5-stack, it can share out agents across everyone's pools.

    05 · Quota-safe & private

    Light on your PC. Light on the API.

    • A built-in request budget never lets background work use more than half your per-minute limit.
    • Finished matches are fetched once and kept on your PC forever.
    • No requests at all while the game is closed and the overlay is hidden.
    • No telemetry. Your history, notes and API key never leave your PC.

    06 · Experimental

    Live match. Your call.

    Once a match has started, see each opponent's current and peak rank. Never during agent select. Off by default, and you decide whether to turn it on.

    Live match Off
    Before you turn this on. Live match uses the Riot Client running on your PC. Riot does not support this, it may stop working after any game update, and Riot may treat tools that show other players' information as a rules violation. This could put your account at risk. Postplant never reads game memory and never runs during agent select.

    08 · FAQ
    
        
    Questions.
    
        
    
          
    
            Do I need an API key? 
            
    Yes, a free one from the community HenrikDev API (not Riot). Join their Discord from docs.henrikdev.xyz, create a Basic key with their bot, and paste it into the app. The app has a step-by-step guide and a Test key button.
    
          
    
          
    
            Can this get me banned? 
            
    The core app only uses a public web API with your own key, after matches finish, the same way stats websites work. It never reads game memory, injects into the game or automates input. The optional live-match feature is different: it uses the Riot Client on your PC, which Riot does not support, so it's off by default and carries a clear warning.
    
          
    
          
    
            Will it slow down my game? 
            
    It's designed not to: under 1% CPU while idle, no animations while nothing changes, and no network requests while the game is closed. Real measurements will be published with the first release.
    
          
    
          
    
            Does it pick agents for me? 
            
    No. The Comp Advisor is something you read. You enter picks by hand, and it never touches agent select.
    
          
    
          
    
            Mac or Linux? 
            
    The game runs on Windows, so the overlay is Windows-only. The main app may also build on macOS and Linux for looking up stats.
    
          
    
          
    
            Is it really free? 
            
    Yes. Open source, no ads, no account, no telemetry.
