Install

Up and running in two minutes.

Run the installer

Windows may show a SmartScreen prompt for new apps. Click More info → Run anyway if the publisher is Postplant. Check the file first with the checksum below if you like.

Get a free API key

Open docs.henrikdev.xyz, join the HenrikDev Discord, and create a Basic key with their bot. It's free and instant. The app walks you through it.

Paste it in and press Test key

The key is stored in Windows Credential Manager and only sent to HenrikDev.

Enter your Riot ID and region

Your recent matches load once, then stay on your PC.

Set Valorant to Windowed Fullscreen

Overlays can't draw over exclusive fullscreen. Then press Ctrl Shift H in game.

Verify your download

Compare the hash with the line in SHA256SUMS.txt. Run this in PowerShell from your Downloads folder:

Get-FileHash .\Postplant_*_x64-setup.exe -Algorithm SHA256

Updates & uninstall

Stays fresh. Leaves clean.

  • The app checks for signed updates and never interrupts a match: updates wait until the game is closed.
  • Pick Stable or Nightly in Settings, or turn automatic checks off.
  • Uninstall from Settings → Apps. Your match history and settings are kept unless you tick "also delete my data".
  • Portable: delete the folder. Use "Remove saved API key" in Settings first if you want the key gone too.
